# Banco Frontend

Aplicación Angular 22 del proyecto. Las instrucciones generales están en el [README principal](../README.md).

Requiere Node 24.

```bash
npm install
npm start               # http://localhost:4200, con /api reenviado a localhost:8080
npm test                # pruebas con Jest
npm run test:coverage   # pruebas con reporte de cobertura
npm run build           # build de producción en dist/banco-frontend/browser
```
